# Platform assets (copied into the native projects)

The `ios/` and `android/` folders are generated with `flutter create .` on a
machine with the Flutter SDK. After generating them, copy:

| File | Destination | Used for |
|---|---|---|
| `ios/olfa_*.wav` | `ios/Runner/` (add to the Runner target, "Copy Bundle Resources") | push sounds (`aps.sound`) |
| `android/raw/olfa_*.wav` | `android/app/src/main/res/raw/` | push sounds + notification channels |

Notification channels (Android 8+), created at first launch by the app:
`olfa_messages` (sound `olfa_message`), `olfa_matches` (`olfa_match`),
`olfa_general` (`olfa_notification`). The backend sends the matching
`channelId`/`sound` (see `soundFor()` in `backend/src/modules/notifications`).

Sounds are generated by `tools/make_sounds.py` (OLFA's own audio, 48 kHz mono,
≤ 1.3 s, peak −2 dBFS — well under Apple's 30 s limit).

## Info.plist / AndroidManifest entries

- `NSMicrophoneUsageDescription` — "OLFA uses the microphone to record voice messages you choose to send." / "يستخدم ألفة الميكروفون لتسجيل الرسائل الصوتية التي تختار إرسالها."
- `NSPhotoLibraryUsageDescription`, `NSCameraUsageDescription` — photos for your profile and chat.
- `NSLocationWhenInUseUsageDescription` — approximate location to show the nearest people first.
- `CFBundleLocalizations` = `ar`, `en` (enables iOS Settings › OLFA › Language).
- Android 13+: `android:localeConfig="@xml/locales_config"` with `ar`, `en`
  (enables Settings › Apps › OLFA › Language); `RECORD_AUDIO`,
  `POST_NOTIFICATIONS`, `ACCESS_COARSE_LOCATION` permissions.
