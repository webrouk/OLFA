# OLFA brand assets

| File | Use |
|---|---|
| `logo-primary.svg` | Full lockup: burgundy icon + Tajawal/Montserrat wordmark |
| `logo-mono-black.svg` / `logo-white.svg` | Monochrome lockups |
| `app-icon-burgundy.svg` / `app-icon-black.svg` | Rounded-square app icons (no wordmark) |
| `ios-app-icon-1024.svg` | Full-bleed source for iOS (export 1024×1024 PNG, iOS applies the mask) |
| `android-adaptive-foreground.svg` + `-background.svg` | Android adaptive icon layers (108dp, symbol in 66dp safe zone) |
| `symbol-*.svg` | Symbol only, for in-app use |

> The symbol was drawn from the brief (two partners forming one shared heart). If an approved master logo file exists, replace these with exports from it — the brief says the existing logo must not be changed.
> The lockups use live text; convert text to outlines in a design tool before final export.
